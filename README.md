# Prime Number Checker - Node.js

A small **Node.js workshop** focused on building and exporting a CommonJS module that checks whether a given number is prime.

## Features

* Prime number validation
* CommonJS module exports
* Basic unit testing with Node.js `assert`
* npm package structure

## Usage

```js
const { isPrime } = require('./index');

console.log(isPrime(7));  // true
console.log(isPrime(10)); // false
```

## Workshop

This project was built as part of the **freeCodeCamp Back End Development and APIs** curriculum.
